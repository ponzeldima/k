1. Аналіз системи B20
Обладнання:

Пункт прибуття (A), верстат 1 (M1), верстат 2 (M2), склад (W).
3 роботи.
Кожен верстат має 3 місця, тобто обробляє до трьох деталей одночасно.
Вхідні величини (позначення методички):

Величина	Закон
Інтервал надходження	exp(40)
Захоплення / вивільнення	unif(8,1), тобто 7…9 с, окремо на кожну дію
Обробка на M1	norm(60,10), значення ≤ 0 відкидаю
Обробка на M2	exp(100)
Переїзди	A–M1 = 6, M1–M2 = 7, M2–W = 5 с, порожнім і з деталлю однаково
Транспортна операція на маршруті i:

Порожній переїзд робота з місця, де він стоїть, до точки завантаження (0 с, якщо він уже там).
Захоплення, 8±1 с. Після цього місце на верстаті-джерелі звільняється.
Переїзд із деталлю.
Вивільнення, 8±1 с. На верстаті-приймачі після цього починається обробка.
Робот вільний і стоїть у точці призначення.
Мої припущення (їх треба зафіксувати в записці):

Розташування лінійне: A–M1–M2–W. Відстані, яких немає в умові, рахую як суми: A–M2 = 13, M1–W = 12, A–W = 18 с. Для другого варіанта це потрібно, бо робот може опинитися будь-де.
Деталь займає місце на верстаті від початку вивільнення на нього до кінця захоплення з нього. Оброблена деталь, яка чекає на робота, теж займає місце, тобто верстат частково блокується.
Робот не бере деталь, якщо на наступному верстаті немає місця. Місце резервується в момент призначення робота. Без цього правила у варіанті 2 можливе взаємне блокування: три роботи тримають деталі біля повного M2, а M2 чекає на робота. Варіант правила обговорюємо в питанні 3.
Площадка прибуття необмежена. Її максимальне заповнення якраз і є шуканою «максимальною місткістю».
Що робить вільний робот у варіанті 2. Якщо задач кілька, він бере найближчу до себе. При рівних відстанях бере ту, що ближче до кінця маршруту (W > M2 > M1), бо це розвантажує вузьке місце. Пріоритет зроблю параметром.
Варіант 1: робот закріплений за маршрутом, після доставки стоїть у точці призначення і повертається порожнім, коли отримує наступну задачу.
Попередня оцінка завантаження (важливо):

M2 — вузьке місце. Одна деталь займає на ньому місце мінімум 8 + 100 + 8 = 116 с плюс час очікування на робота.
Завантаження M2: ρ₂ ≈ (1/40 · 116) / 3 ≈ 0,97. Це ще без резервування місця на час переїзду робота. Якщо резервувати місце з моменту призначення, виходить ρ₂ ≈ 1,05–1,1, тобто система нестійка.
Отже, система працює на межі пропускної здатності. Найімовірніше, саме тому від способу закріплення роботів так сильно залежить результат: швидший забір деталі з M2 зменшує ефективний час, який вона займає місце.
Можливий наслідок: черга на площадці прибуття росте без обмеження, і перехідний період не закінчується. Методичка для такого випадку прямо каже змінити відгук або параметри.
Тому окремо пропоную експеримент «пропускна здатність»: змінювати середній інтервал надходження (наприклад, 36…60 с) і для кожного варіанта знайти межу стійкості.
Робочий цикл робота на маршрутах: приблизно 28, 30 і 26 с. Тому у варіанті 1 завантаження роботів буде 0,65–0,75.
2. Формалізм (рекомендація)
Рекомендую стохастичну мережу Петрі з багатоканальними переходами, пріоритетами й випадковим вирішенням конфліктів. Двигун пишу сам за алгоритмами 3.1 і 3.3 методички, а мережу генерує код для кожного з двох варіантів.

Чому не мережа МО: деталі одночасно потрібні два ресурси (робот і місце на наступному верстаті), а в робота є місце розташування. Це погано вкладається в мережу МО. Мережа Петрі дає це природно, а «найближчий робот» реалізується пріоритетами переходів.

Ескіз мережі:

Позиції:
Queue_A, M1_free(3), M1_loaded, M1_done, M2_free(3), M2_loaded, M2_done, Warehouse;
для кожного робота: R_k@A, R_k@M1, R_k@M2, R_k@W, а також проміжні стани R_k_toPick_i, R_k_grab_i, R_k_carry_i, R_k_release_i.
Призначення Go(k, l, i):
входи: робот k у місці l, деталь у джерелі маршруту i, вільне місце на верстаті-приймачі (для маршруту на склад не потрібне);
затримка: відстань від l до точки завантаження;
пріоритет = −відстань, тому в конфлікті виграє найближчий робот.
У варіанті 1 переходи Go створюються лише для «свого» маршруту робота, у варіанті 2 — для всіх.
Далі ланцюжок переходів:
Grab(k,i), unif(8,1): повертає маркер у M*_free джерела;
Carry(k,i), фіксована затримка;
Release(k,i), unif(8,1): ставить деталь на верстат, робот опиняється в точці призначення.
Обробка: Proc1 norm(60,10) і Proc2 exp(100). Це багатоканальні переходи, кількість каналів обмежує M*_free.
Arrival: exp(40).
Розширення, без якого не вийде розподіл часу перебування. Маркери-деталі будуть об'єктами з id і часом надходження: позиції з деталями працюють як FIFO-списки, а канал переходу зберігає свою деталь. Маркери-ресурси (роботи, місця) лишаються анонімними. Це дає час перебування кожної деталі без порушення семантики мережі.

"""Генератори випадкових чисел.

Базова рівномірно розподілена величина ζ ∈ (0, 1] береться з генератора
Mersenne Twister (random.Random), а всі інші закони отримуються власними
формулами:
  exp(m)      : r = -m · ln(ζ)                       (метод оберненої функції)
  unif(d, s)  : r = d - s + 2s · ζ                   (рівномірний на (d-s, d+s))
  norm(d, s)  : полярний метод Марсальї–Брея
  const(d)    : r = d

Кожне джерело випадковості моделі має власний потік (Stream), що дає змогу
використовувати спільні випадкові числа при порівнянні альтернатив.
"""

from __future__ import annotations

import math
import random
from dataclasses import dataclass


class Stream:
    """Окремий потік випадкових чисел із власним зерном."""

    def __init__(self, seed: int | str):
        self._rnd = random.Random(seed)
        self._spare_normal: float | None = None

    def zeta(self) -> float:
        """Рівномірна величина на (0, 1]."""
        return 1.0 - self._rnd.random()

    def exponential(self, mean: float) -> float:
        return -mean * math.log(self.zeta())

    def uniform(self, center: float, half_width: float) -> float:
        return center - half_width + 2.0 * half_width * self._rnd.random()

    def standard_normal(self) -> float:
        """Полярний метод Марсальї–Брея: генерує пару, другу зберігає."""
        if self._spare_normal is not None:
            value, self._spare_normal = self._spare_normal, None
            return value
        while True:
            a1 = 2.0 * self._rnd.random() - 1.0
            a2 = 2.0 * self._rnd.random() - 1.0
            s = a1 * a1 + a2 * a2
            if 0.0 < s <= 1.0:
                break
        beta = math.sqrt(-2.0 * math.log(s) / s)
        self._spare_normal = a2 * beta
        return a1 * beta

    def normal(self, mean: float, std: float) -> float:
        return mean + std * self.standard_normal()

    def shuffle(self, items: list) -> None:
        self._rnd.shuffle(items)

    def random(self) -> float:
        return self._rnd.random()


@dataclass(frozen=True)
class Dist:
    """Опис закону розподілу у позначеннях методички: exp(d), norm(d,s), unif(d,s), d."""

    kind: str
    a: float
    b: float = 0.0

    def sample(self, stream: Stream) -> float:
        if self.kind == "const":
            return self.a
        if self.kind == "exp":
            return stream.exponential(self.a)
        if self.kind == "unif":
            return stream.uniform(self.a, self.b)
        if self.kind == "norm":
            # усічений нормальний закон: час обробки не може бути від'ємним
            while True:
                value = stream.normal(self.a, self.b)
                if value > 0.0:
                    return value
        raise ValueError(f"Невідомий закон розподілу: {self.kind}")

    @property
    def mean(self) -> float:
        return self.a

    def __str__(self) -> str:
        if self.kind == "const":
            return f"{self.a:g}"
        if self.kind == "exp":
            return f"exp({self.a:g})"
        return f"{self.kind}({self.a:g},{self.b:g})"


def const(d: float) -> Dist:
    return Dist("const", d)


def exp(mean: float) -> Dist:
    return Dist("exp", mean)


def unif(center: float, half_width: float) -> Dist:
    return Dist("unif", center, half_width)


def norm(mean: float, std: float) -> Dist:
    return Dist("norm", mean, std)

Відповідність елементам формалізму (табл. 3.1 методички):

# --------------------------------------------------------------------------- Queue
class Queue(Element):
    """Місце зберігання деталей на ділянці прибуття.

    Деталь перебуває тут від надходження до завершення її захоплення роботом.
    """

    def __init__(self, name: str, model: "Model", route_out: int):
        super().__init__(name, model)
        self.route_out = route_out
        self.length = 0
        self.max_length = 0
        self._sum_length = 0.0
        self._hist: dict[int, float] = {}  # довжина -> сумарний час перебування в цьому стані

    def put(self, part: Part, t: float) -> None:
        self.length += 1
        self.max_length = max(self.max_length, self.length)
        part.t_ready[self.route_out] = t
        self.model.add_task(Task(route=self.route_out, part=part, t_ready=t))

    def grab_done(self, t: float) -> None:
        self.length -= 1

    def update_stats(self, dt: float) -> None:
        self._sum_length += self.length * dt
        self._hist[self.length] = self._hist.get(self.length, 0.0) + dt

    def reset_stats(self) -> None:
        self._sum_length = 0.0
        self._hist = {}
        self.max_length = self.length

    def mean_length(self, period: float) -> float:
        return self._sum_length / period if period > 0 else 0.0

    def length_distribution(self, period: float) -> dict[int, float]:
        return {k: v / period for k, v in sorted(self._hist.items())} if period > 0 else {}

    def state_str(self) -> str:
        return f"A={self.length}"

FREE, RESERVED, LOADING, BUSY, BLOCKED, UNLOADING = (
    "free", "reserved", "loading", "busy", "blocked", "unloading",

MACHINE_STATES = (FREE, RESERVED, LOADING, BUSY, BLOCKED, UNLOADING)
_STATE_CHAR = {FREE: ".", RESERVED: "r", LOADING: "l", BUSY: "B", BLOCKED: "x", UNLOADING: "u"}


@dataclass
class MachineChannel:
    index: int
    state: str = FREE
    part: Part | None = None
    tnext: float = INF


class Machine(Element):
    """Верстат з ЧПК – багатоканальна СМО без черги.

    Стани каналу (місця):
      free      – вільне;
      reserved  – зарезервоване під деталь, яку везе робот (політика reserve);
      loading   – робот вивільняє на нього деталь;
      busy      – обробка;
      blocked   – обробку завершено, маршрут виходу блокований до приходу робота;
      unloading – робот захоплює деталь.
    """

    def __init__(self, name: str, model: "Model", capacity: int, dist, stream, route_out: int):
        super().__init__(name, model)
        self.channels = [MachineChannel(i) for i in range(capacity)]
        self.dist = dist
        self.stream = stream
        self.route_out = route_out
        self.incoming = 0  # роботи, призначені на доставку сюди, але ще без місця (physical)
        self.waiting_robots: deque = deque()  # роботи з деталлю, що чекають вільного місця
        self.processed = 0
        self._state_time = {s: 0.0 for s in MACHINE_STATES}

    @property
    def capacity(self) -> int:
        return len(self.channels)

    def count(self, state: str) -> int:
        return sum(1 for ch in self.channels if ch.state == state)

    def _first(self, state: str) -> MachineChannel | None:
        return next((ch for ch in self.channels if ch.state == state), None)

    def next_time(self) -> float:
        return min(ch.tnext for ch in self.channels)

    # --- події обробки
    def out_act(self, t: float) -> None:
        due = [ch for ch in self.channels if ch.tnext == t]
        self.model.streams.ties.shuffle(due)
        for ch in due:
            ch.state = BLOCKED
            ch.tnext = INF
            self.processed += 1
            ch.part.t_ready[self.route_out] = t
            self.model.log(t, self.name, f"кінець обробки деталі #{ch.part.id} (місце {ch.index}) -> блокування")
            self.model.add_task(Task(route=self.route_out, part=ch.part, t_ready=t, channel=ch))

    # --- умова блокування маршруту входу B(S,t)
    def can_dispatch_to(self) -> bool:
        free = self.count(FREE)
        if self.model.params.slot_policy == "reserve":
            return free > 0
        # physical: дозволяємо не більше одного «зайвого» робота на верстат,
        # що виключає взаємне блокування роботів
        return self.incoming <= free

    def on_dispatch(self) -> MachineChannel | None:
        if self.model.params.slot_policy == "reserve":
            ch = self._first(FREE)
            ch.state = RESERVED
            return ch
        self.incoming += 1
        return None

    def take_for_release(self, reserved: MachineChannel | None) -> MachineChannel | None:
        """Робот підвіз деталь: повертає місце для вивільнення або None, якщо треба чекати."""
        if reserved is not None:
            reserved.state = LOADING
            return reserved
        ch = self._first(FREE)
        if ch is None:
            return None
        self.incoming -= 1
        ch.state = LOADING
        return ch

    def release_done(self, ch: MachineChannel, part: Part, t: float) -> None:
        ch.state = BUSY
        ch.part = part
        ch.tnext = t + self.dist.sample(self.stream)
        self.model.log(t, self.name, f"початок обробки деталі #{part.id} (місце {ch.index}), кінець о {ch.tnext:.3f}")

    def start_grab(self, ch: MachineChannel) -> None:
        ch.state = UNLOADING

    def grab_done(self, ch: MachineChannel, t: float) -> None:
        ch.state = FREE
        ch.part = None
        # розблокування робота, який чекав місця з деталлю (план події в момент t)
        if self.waiting_robots:
            robot = self.waiting_robots.popleft()
            slot = self.take_for_release(None)
            robot.transport.start_release(robot, slot, t)

    # --- статистика
    def update_stats(self, dt: float) -> None:
        for ch in self.channels:
            self._state_time[ch.state] += dt

    def reset_stats(self) -> None:
        self._state_time = {s: 0.0 for s in MACHINE_STATES}
        self.processed = 0

    def utilization(self, period: float) -> dict[str, float]:
        """Частки часу (на одне місце), усереднені за трьома місцями."""
        denom = period * self.capacity
        share = {s: v / denom for s, v in self._state_time.items()} if denom > 0 else {}
        occupied = 1.0 - share.get(FREE, 1.0)
        return {
            "occupied": occupied,
            "processing": share.get(BUSY, 0.0),
            "blocked": share.get(BLOCKED, 0.0),
            "handling": share.get(LOADING, 0.0) + share.get(UNLOADING, 0.0),
            "reserved": share.get(RESERVED, 0.0),
        }

    def state_str(self) -> str:
        return f"{self.name}[{''.join(_STATE_CHAR[ch.state] for ch in self.channels)}]"

@dataclass(eq=False)
class Robot:
    """Канал транспортної СМО."""

    id: int
    location: str
    allowed_routes: tuple[int, ...]
    transport: "Transport" = None
    state: str = R_FREE
    tnext: float = INF

    dest_slot: MachineChannel | None = None

class Transport(Element):
    """СМО транспортування деталей роботами.

    Стратегія 1: три одноканальні СМО, кожна обслуговує лише свій маршрут.
    Стратегія 2: одна триканальна СМО, що обслуговує всі маршрути.
    """

    def __init__(self, name: str, model: "Model", robots: list[Robot]):
        super().__init__(name, model)
        self.robots = robots
        for r in robots:
            r.transport = self

    def next_time(self) -> float:
        return min(r.tnext for r in self.robots)

    def _handling(self) -> float:
        return self.model.params.handling.sample(self.model.streams.handling)

    # --- початок обслуговування (призначення робота на заявку)
    def assign(self, robot: Robot, task: Task, t: float) -> None:
        route = self.model.routes[task.route]
        robot.task = task
        robot.route = route
        robot.jobs[route.index] = robot.jobs.get(route.index, 0) + 1
        robot.dest_slot = route.dest.on_dispatch() if isinstance(route.dest, Machine) else None
        travel = self.model.params.distance(robot.location, route.pickup)
        self.model.log(
            t, f"Robot{robot.id}",
            f"призначено на маршрут {route.index} ({route.pickup}->{route.drop}) для деталі #{task.part.id}, "
            f"холостий хід {robot.location}->{route.pickup} {travel:g}",
        )
        if travel > 0:
            robot.state = R_TO_PICKUP
            robot.tnext = t + travel
        else:
            self._start_grab(robot, t)

    def _start_grab(self, robot: Robot, t: float) -> None:
        robot.location = robot.route.pickup
        robot.state = R_GRAB
        robot.tnext = t + self._handling()
        robot.task.part.t_grab[robot.route.index] = t
        if robot.task.channel is not None:
            robot.route.source.start_grab(robot.task.channel)
        self.model.log(t, f"Robot{robot.id}", f"початок захоплення деталі #{robot.task.part.id} у {robot.location}")

    def _start_carry(self, robot: Robot, t: float) -> None:
        route = robot.route
        # деталь знята з місця-джерела
        if robot.task.channel is not None:
            route.source.grab_done(robot.task.channel, t)
        else:
            route.source.grab_done(t)
        robot.state = R_CARRY
        robot.tnext = t + self.model.params.distance(route.pickup, route.drop)
        self.model.log(t, f"Robot{robot.id}", f"деталь #{robot.task.part.id} захоплено, хід {route.pickup}->{route.drop}")

    def _arrive(self, robot: Robot, t: float) -> None:
        route = robot.route
        robot.location = route.drop
        if isinstance(route.dest, Machine):
            slot = route.dest.take_for_release(robot.dest_slot)
            if slot is None:
                # маршрут заблоковано: робот тримає деталь і чекає вільного місця
                robot.state = R_WAIT
                robot.tnext = INF
                route.dest.waiting_robots.append(robot)
                self.model.log(t, f"Robot{robot.id}", f"на {route.drop} немає місця, очікування з деталлю #{robot.task.part.id}")
                return
            self.start_release(robot, slot, t)
        else:
            self.start_release(robot, None, t)

    def start_release(self, robot: Robot, slot: MachineChannel | None, t: float) -> None:
        robot.dest_slot = slot
        robot.state = R_RELEASE

    # ------------------------------------------------------------------ диспетчер
    def dispatch(self, t: float) -> None:
        """Події входу: призначення вільних роботів на заявки на перевезення.

        Обирається пара (робот, маршрут) з найменшою відстанню холостого ходу;
        при рівності – маршрут з меншим рангом (ближчий до складу), далі – раніше
        готова заявка, далі – випадково. Заявки кожного маршруту – FIFO.
        """
        rank = self.params.route_rank
        while True:
            best = None
            for tr in self.transports:
                for robot in tr.free_robots():
                    for r in robot.allowed_routes:
                        queue = self.tasks[r]
                        if not queue:
                            continue
                        route = self.routes[r]
                        if route.blocked():
                            continue
                        key = (self.params.distance(robot.location, route.pickup), rank[r - 1],
                               queue[0].t_ready, self.streams.ties.random())
                        if best is None or key < best[0]:
                            best = (key, tr, robot, r)
            if best is None:
                return
            _, tr, robot, r = best
            tr.assign(robot, self.tasks[r].popleft(), t)

    def run(self, t_end: float, t_warmup: float = 0.0,

        observer – функція, що викликається кожні observe_every секунд (для аналізу

        self.t_end = t_end
        self._created_at_reset = 0
        pending_reset = t_warmup > 0
        next_obs = observe_every if observe_every else INF
        self.dispatch(0.0)
        self.log_state(0.0)
        while True:
            t_next = self._next_event_time()
            # службові моменти: кінець перехідного періоду та спостереження
            while True:

                if t_service > min(t_next, t_end):

                if pending_reset and t_service == t_warmup:
                    self.reset_stats()
                    pending_reset = False

                    next_obs += observe_every

            self.log_state(t)
        return self

def _mean(xs: list[float]) -> float:
    return sum(xs) / len(xs) if xs else math.nan


def _std(xs: list[float]) -> float:
    if len(xs) < 2:
        return math.nan
    m = _mean(xs)
    return math.sqrt(sum((x - m) ** 2 for x in xs) / (len(xs) - 1))


def _quantile(sorted_xs: list[float], q: float) -> float:
    if not sorted_xs:
        return math.nan
    pos = q * (len(sorted_xs) - 1)
    lo, hi = math.floor(pos), math.ceil(pos)
    return sorted_xs[lo] + (sorted_xs[hi] - sorted_xs[lo]) * (pos - lo)

def _parts_in_system(m: Model) -> int:
    on_machines = sum(1 for mach in (m.m1, m.m2) for ch in mach.channels if ch.part is not None)
    carried = sum(1 for r in m.robots if r.task is not None and r.state in ("loaded_move", "wait_slot", "release"))
    # деталі, що захоплюються з машини, ще лежать на місці (ch.part) – не рахуємо двічі
    grabbing_from_buffer = sum(1 for r in m.robots if r.state == "grab" and r.task.channel is None)
    return m.buffer.length + on_machines + carried + 0 * grabbing_from_buffer

def variants(strategy: str | None, policy: str | None) -> list[tuple[str, str]]:
    ss = [strategy] if strategy else [DEDICATED, NEAREST]
    ps = [policy] if policy else [RESERVE, PHYSICAL]
    return [(s, p) for p in ps for s in ss]


def _one(args):
    params, seed, t_end, t_warmup, keep_sojourn = args
    res, soj = simulate(params, seed, t_end, t_warmup)
    return res, (soj if keep_sojourn else None)


def replicate(params: Params, n: int, t_end: float, t_warmup: float,
              seed0: int = 1, jobs: int = 1, keep_sojourn: bool = False):
    """n повторних прогонів з зернами seed0..seed0+n-1.

    Однакові зерна для різних варіантів дають спільні випадкові числа.
    """
    tasks = [(params, seed0 + i, t_end, t_warmup, keep_sojourn) for i in range(n)]
    if jobs > 1:
        with ProcessPoolExecutor(max_workers=jobs) as ex:
            out = list(ex.map(_one, tasks))
    else:
        out = [_one(t) for t in tasks]
    results = [r for r, _ in out]
    sojourns = [s for _, s in out] if keep_sojourn else None
    return results, sojourns


def summarize(values, beta: float = 0.95) -> dict:
    """Середнє, стандартне відхилення та довірчий інтервал (Стьюдент)."""
    x = np.asarray([v for v in values if not (isinstance(v, float) and math.isnan(v))], dtype=float)
    n = len(x)
    if n == 0:
        return {"n": 0, "mean": math.nan, "std": math.nan, "ci": math.nan}
    mean = float(x.mean())
    std = float(x.std(ddof=1)) if n > 1 else math.nan
    ci = float(stats.t.ppf((1 + beta) / 2, n - 1) * std / math.sqrt(n)) if n > 1 else math.nan
    return {"n": n, "mean": mean, "std": std, "ci": ci}

def write_csv(path: Path, rows: list[dict]) -> None:
    if not rows:
        return
    keys: list[str] = []
    for r in rows:
        for k in r:
            if k not in keys:
                keys.append(k)
    with path.open("w", newline="", encoding="utf-8") as f:
        w = csv.DictWriter(f, fieldnames=keys)
        w.writeheader()
        w.writerows(rows)

"""Визначення тривалості перехідного періоду (формули 3.1–3.2 методички).

from __future__ import annotations

import math

METRICS = ("throughput_per_hour", "sojourn_mean", "buffer_mean", "M2_occupied", "robots_util_mean")


def _snapshot(m: Model) -> dict:
    t = m.tcurr
    soj = [p.t_done - p.t_arrival for p in m.completed]
    busy = [sum(v for s, v in r.state_time.items() if s != "free") / t for r in m.robots]
    return {
        "t": t,
        "throughput_per_hour": m.completed_total / t * 3600,
        "sojourn_mean": sum(soj) / len(soj) if soj else math.nan,
        "buffer_mean": m.buffer.mean_length(t),
        "M2_occupied": m.m2.utilization(t)["occupied"],
        "robots_util_mean": sum(busy) / len(busy),
    }

"""Порівняння способів закріплення роботів (дисперсійний аналіз, формули 3.10–3.11).

Фактор – спосіб закріплення роботів (q = 2 рівні), для кожного рівня p прогонів
зі спільними випадковими числами (однакові зерна).
  D_f = p · Σ_j (ȳ_j − ȳ)² / (q·p − 1)          – факторна дисперсія (3.10)
  D_r = Σ_j Σ_s (y_js − ȳ_j)² / (q(p − 1))       – залишкова дисперсія (3.11)
  F = D_f / D_r порівнюється з F_кр(α; q−1, q(p−1)).
Додатково (класичний однофакторний ANOVA) – F = [S_f/(q−1)] / [S_r/(q(p−1))]
і парний t-критерій для різниць при спільних випадкових числах.
"""

from __future__ import annotations

import numpy as np
from scipy import stats

from ..params import DEDICATED, NEAREST, Params

def anova(groups: list[np.ndarray], alpha: float = 0.05) -> dict:
    q = len(groups)
    p = len(groups[0])
    means = np.array([g.mean() for g in groups])
    grand = np.concatenate(groups).mean()
    s_f = p * ((means - grand) ** 2).sum()
    s_r = sum(((g - g.mean()) ** 2).sum() for g in groups)
    d_f_guide = s_f / (q * p - 1)
    d_r = s_r / (q * (p - 1))
    df1, df2 = q - 1, q * (p - 1)
    f_guide = d_f_guide / d_r if d_r > 0 else np.inf
    f_classic = (s_f / df1) / d_r if d_r > 0 else np.inf
    f_crit = stats.f.ppf(1 - alpha, df1, df2)
    return {
        "S_f": s_f, "S_r": s_r, "D_f(3.10)": d_f_guide, "D_r(3.11)": d_r,
        "F(3.10/3.11)": f_guide, "F_classic": f_classic, "F_crit": f_crit,
        "p_value": float(stats.f.sf(f_classic, df1, df2)),
        "significant": bool(f_classic > f_crit),
    }

    for strategy in (DEDICATED, NEAREST):
        runs[strategy], _ = replicate(base.with_(strategy=strategy, slot_policy=policy), reps, t_end, t_warmup, jobs=jobs)

    summary = []
    for strategy, results in runs.items():
        row = {"strategy": strategy, "slot_policy": policy}
        for k in KEY_OUTPUTS:
            s = summarize([r[k] for r in results])
            row[k] = s["mean"]
            row[k + "_ci"] = s["ci"]
        summary.append(row)

    tests = []
    for resp in RESPONSES:
        a = np.array([r[resp] for r in runs[DEDICATED]], dtype=float)
        b = np.array([r[resp] for r in runs[NEAREST]], dtype=float)
        res = {"response": resp, "slot_policy": policy,
               "mean_dedicated": a.mean(), "mean_nearest": b.mean(), **anova([a, b])}
        diff = b - a

        res.update({"paired_diff_mean": diff.mean(), "paired_diff_ci": summarize(diff)["ci"],
                    "paired_t": float(t_stat), "paired_p": float(t_p)})
        tests.append(res)

    return summary, tests, raw

"""Розподіл часу проходження деталей: гістограма, підбір закону, критерій χ².

Порядок (методичка, п. 3.1.4): масив спостережень → гістограма частот →
гіпотеза про закон → оцінка параметрів → перевірка за критерієм χ²:
  χ² = Σ (n_i − n·p_i)² / (n·p_i),  df = k − 1 − (кількість оцінених параметрів),
інтервали з n·p_i < 5 об'єднуються з сусідніми.
"""

from __future__ import annotations

import math

import numpy as np
from scipy import stats

from ..params import Params
from .common import replicate

# закон -> (розподіл scipy, фіксовані параметри при оцінці, кількість оцінених параметрів)
CANDIDATES = {
    "normal": (stats.norm, {}, 2),
    "exponential (shifted)": (stats.expon, {}, 2),
    "gamma (shifted)": (stats.gamma, {}, 3),
    "lognormal (shifted)": (stats.lognorm, {}, 3),
    "erlang/gamma (loc=0)": (stats.gamma, {"floc": 0.0}, 2),
}


def histogram(data: np.ndarray, bins: int) -> tuple[np.ndarray, np.ndarray]:
    counts, edges = np.histogram(data, bins=bins)
    return counts, edges


def chi_square(data: np.ndarray, dist, params: tuple, n_params: int, bins: int) -> dict:
    counts, edges = histogram(data, bins)
    # крайні інтервали розширюємо до нескінченності, щоб Σ p_i = 1
    cdf = dist.cdf(edges, *params)
    cdf[0], cdf[-1] = 0.0, 1.0
    probs = np.diff(cdf)
    n = len(data)
    obs, exp_ = [], []
    acc_o = acc_e = 0.0
    for o, p in zip(counts, probs):
        acc_o += o
        acc_e += n * p
        if acc_e >= 5:
            obs.append(acc_o)
            exp_.append(acc_e)
            acc_o = acc_e = 0.0
    if acc_e > 0 and exp_:
        obs[-1] += acc_o
        exp_[-1] += acc_e
    obs, exp_ = np.array(obs), np.array(exp_)
    chi2 = float(((obs - exp_) ** 2 / exp_).sum())
    df = len(obs) - 1 - n_params
    crit = float(stats.chi2.ppf(0.95, df)) if df > 0 else math.nan
    return {"chi2": chi2, "df": df, "chi2_crit_0.05": crit, "intervals": len(obs),
            "accepted": bool(df > 0 and chi2 < crit)}


def fit_all(data: np.ndarray, bins: int) -> list[dict]:
    rows = []
    for name, (dist, fixed, k) in CANDIDATES.items():
        if name.startswith("exponential"):
            params = (float(data.min()), float(data.mean() - data.min()))
        else:
            params = dist.fit(data, **fixed)
        res = chi_square(data, dist, params, k, bins)
        rows.append({"law": name, "params": ", ".join(f"{v:.4g}" for v in params), **res})
    rows.sort(key=lambda r: r["chi2"])
    return rows


def run(params: Params, reps: int, t_end: float, t_warmup: float, jobs: int,
        bins: int, thin: int) -> dict:
    _, sojourns = replicate(params, reps, t_end, t_warmup, jobs=jobs, keep_sojourn=True)
    # проріджування зменшує автокореляцію сусідніх деталей
    data = np.concatenate([np.asarray(s[::thin], dtype=float) for s in sojourns])
    counts, edges = histogram(data, bins)
    hist = [{"left": float(edges[i]), "right": float(edges[i + 1]), "count": int(counts[i]),
             "freq": float(counts[i] / len(data))} for i in range(len(counts))]
    describe = {
        "n": int(len(data)), "mean": float(data.mean()), "std": float(data.std(ddof=1)),
        "cv": float(data.std(ddof=1) / data.mean()), "min": float(data.min()),
        "p50": float(np.quantile(data, 0.5)), "p90": float(np.quantile(data, 0.9)),
        "p95": float(np.quantile(data, 0.95)), "max": float(data.max()),
        "skew": float(stats.skew(data)),
    }
    return {"describe": describe, "histogram": hist, "fits": fit_all(data, bins), "data": data}

    for s, p in variants(a.strategy, a.policy):
        params = _params(a, s, p)
        res = distribution.run(params, a.reps, a.t_end, a.warmup, a.jobs, a.bins, a.thin)
        tag = f"{s}_{p}_a{a.arrival:g}"
        print(f"\n=== Розподіл часу проходження: {s} / {p}, інтервал надходження exp({a.arrival:g}) ===")
        print("  " + ", ".join(f"{k}={v:.2f}" if isinstance(v, float) else f"{k}={v}"
                               for k, v in res["describe"].items()))
        print_table(res["fits"], ["law", "params", "chi2", "df", "chi2_crit_0.05", "accepted"],
                    ["закон", "параметри", "χ²", "df", "χ² кр", "прийнято"])
        write_csv(d / f"dist_hist_{tag}.csv", res["histogram"])
        write_csv(d / f"dist_fits_{tag}.csv", res["fits"])
        write_json(d / f"dist_describe_{tag}.json", res["describe"])
        (d / f"dist_data_{tag}.txt").write_text("\n".join(f"{x:.4f}" for x in res["data"]), encoding="utf-8")
        print(f"-> {d}/dist_*_{tag}.*")


def build_parser() -> argparse.ArgumentParser:
    ap = argparse.ArgumentParser(prog="fms", description="Імітаційна модель роботизованої ГВС (B20)")
    sub = ap.add_subparsers(dest="cmd", required=True)

    def common(sp, t_end=200_000.0, warm=20_000.0, reps=10):
        sp.add_argument("--strategy", choices=[DEDICATED, NEAREST], help="за замовчуванням – обидві")
        sp.add_argument("--policy", choices=[RESERVE, PHYSICAL], help="за замовчуванням – обидві")
        sp.add_argument("--arrival", type=float, default=40.0, help="середній інтервал надходження, с")
        sp.add_argument("--t-end", type=float, default=t_end, help="час моделювання, с")
        sp.add_argument("--warmup", type=float, default=warm, help="перехідний період, с")
        sp.add_argument("--reps", type=int, default=reps, help="кількість прогонів")
        sp.add_argument("--seed", type=int, default=1)
        sp.add_argument("--jobs", type=int, default=max(1, (os.cpu_count() or 2) - 1))
        sp.add_argument("--out", default="results")

    sp = sub.add_parser("run", help="один прогін і всі вихідні змінні"); common(sp); sp.set_defaults(f=cmd_run)
    sp = sub.add_parser("trace", help="протокол подій"); common(sp)
    sp.add_argument("--until", type=float, default=600.0)
    sp.add_argument("--print", action="store_true")
    sp.set_defaults(f=cmd_trace)
    sp = sub.add_parser("verify", help="таблиця верифікації"); common(sp, 100_000, 10_000, 5); sp.set_defaults(f=cmd_verify)
    sp = sub.add_parser("warmup", help="перехідний період"); common(sp, 300_000, 0)
    sp.add_argument("--runs", type=int, default=5)
    sp.add_argument("--step", type=float, default=1_000.0)
    sp.add_argument("--eps", type=float, default=0.05, help="точність, частка від рівня відгуку")
    sp.set_defaults(f=cmd_warmup)
    sp = sub.add_parser("reps", help="кількість повторних прогонів"); common(sp)
    sp.add_argument("--pilot", type=int, default=20)
    sp.add_argument("--eps", type=float, default=0.02)
    sp.set_defaults(f=cmd_reps)
    sp = sub.add_parser("compare", help="порівняння способів закріплення + ANOVA"); common(sp, reps=30)
    sp.set_defaults(f=cmd_compare)
    sp = sub.add_parser("capacity", help="пропускна здатність vs інтенсивність надходження"); common(sp)
    sp.add_argument("--arrivals", help="список середніх інтервалів через кому")
    sp.set_defaults(f=cmd_capacity)
    sp = sub.add_parser("dist", help="розподіл часу проходження + χ²"); common(sp, reps=20)
    sp.add_argument("--bins", type=int, default=20)
    sp.add_argument("--thin", type=int, default=5, help="брати кожну k-ту деталь")
    sp.set_defaults(f=cmd_dist)
    return ap


def main(argv=None):
    if hasattr(sys.stdout, "reconfigure"):

хід з деталлю → [очікування місця] → вивільнення unif(8,1). Місце на верстаті-джерелі звільняється
по завершенні захоплення; обробка починається по завершенні вивільнення.

## Припущення моделі

1. Пункти розташовані на лінії A – M1 – M2 – W; відстані A–M2 = 13, M1–W = 12, A–W = 18 с.
2. Робот після вивільнення залишається в точці призначення.
3. Варіант 2: обирається пара (вільний робот, заявка) з найменшою відстанню холостого ходу; при

4. Політика місць на верстаті (`--policy`):
   - `reserve` – робот призначається лише якщо на верстаті-приймачі є вільне місце, воно резервується

   - `physical` – місце займається лише при вивільненні; робот з деталлю чекає біля заповненого

5. Час обробки на M1 – усічений нормальний закон (значення ≤ 0 відкидаються).
6. Одночасні події виконуються у випадковому порядку; завершення обслуговування – раніше за надходження.

Так, усі команди запускають одну й ту саму модель. Окремі вони тому, що кожна дає матеріал для свого пункту записки, а методичка вимагає їх усі.

Команда	Пункт записки / вимога методички	Що вона дає
run	— (для себе)	Один прогін, щоб подивитися всі числа й налагодити модель.
trace	Розділ 3, додаток: обов'язковий «фрагмент протоколу подій, який доводить правильність алгоритму»	Покроковий журнал подій (хто, коли, що змінилось).

Тобто це не дублювання. Кожен експеримент має свою процедуру (свою серію прогонів і свою статистику), і я виніс кожну в окрему команду, щоб для записки її можна було перезапустити одним рядком.

Про 20 прогонів і seed. Результати 20 прогонів різні: --seed задає лише перше зерно серії. Прогін i отримує зерно seed + i, тобто 1, 2, …, 20 (функція replicate у common.py). Однаковим буде лише повторний запуск усієї серії з тим самим --seed. Тому seed тут потрібен для відтворюваності: викладач запустить і отримає ті самі цифри.

Навіщо взагалі кілька прогонів:

Один прогін — одна випадкова реалізація. Наприклад, buffer_max між прогонами коливається приблизно ±80 деталей (σ ≈ 77 з команди reps). З одного прогону не видно, чи різниця між варіантами реальна, чи це випадковість.
Методичка вимагає прямо: результат експерименту має бути середнім повторних замірів, а їх кількість рахують за p = 20(σ/ε)².
ANOVA без повторів неможлива: F-критерій порівнює розкид між варіантами з розкидом всередині варіанта, а розкид всередині дає лише серія прогонів.
Спільні випадкові числа: обидва варіанти проганяються на тих самих зернах 1…20, тобто на однакових потоках надходжень і часів обробки. Різниця між ними тоді пояснюється способом закріплення, а не тим, що одному «пощастило» з потоком деталей.

"""Графіки за збереженими результатами експериментів."""

from __future__ import annotations

import csv
import json
from pathlib import Path

import matplotlib

matplotlib.use("Agg")
import matplotlib.pyplot as plt  # noqa: E402
import numpy as np  # noqa: E402
from scipy import stats  # noqa: E402

# кольори: стовпці – світлий крок синьої шкали, криві – категоріальні слоти у фіксованому порядку
SURFACE = "#fcfcfb"
INK = "#0b0b0b"
INK_2 = "#52514e"
GRID = "#e4e3df"
BAR = "#9ec5f4"
CURVES = ("#eb6834", "#1baf7a", "#6250d6")
LINESTYLES = ("-", "--", ":")  # друге кодування: колір не єдиний розрізнювач

SCIPY_DIST = {
    "normal": stats.norm,
    "exponential (shifted)": stats.expon,
    "gamma (shifted)": stats.gamma,
    "lognormal (shifted)": stats.lognorm,
    "erlang/gamma (loc=0)": stats.gamma,
}
LAW_UA = {
    "normal": "нормальний",
    "exponential (shifted)": "експоненціальний (зсунутий)",
    "gamma (shifted)": "гамма (зсунутий)",
    "lognormal (shifted)": "логнормальний (зсунутий)",
    "erlang/gamma (loc=0)": "гамма / Ерланга (без зсуву)",
}
STRATEGY_UA = {"dedicated": "варіант 1 (закріплені роботи)", "nearest": "варіант 2 (найближчий робот)"}


def available_tags(results: Path) -> list[str]:
    return sorted(p.name[len("dist_data_"):-len(".txt")] for p in results.glob("dist_data_*.txt"))


def _title(tag: str) -> str:
    parts = tag.split("_")
    if len(parts) == 3 and parts[2].startswith("a"):
        strategy, policy, arrival = parts
        return f"{STRATEGY_UA.get(strategy, strategy)}, політика {policy}, інтервал надходження exp({arrival[1:]}) с"
    return tag


def plot_distribution(results: Path, tag: str, top: int = 3, out: Path | None = None, dpi: int = 200) -> Path:
    data = np.loadtxt(results / f"dist_data_{tag}.txt")
    with (results / f"dist_hist_{tag}.csv").open(encoding="utf-8") as f:
        hist = list(csv.DictReader(f))
    fits = json.loads((results / f"dist_fits_{tag}.json").read_text(encoding="utf-8"))
    if fits and "params_raw" not in fits[0]:
        raise ValueError("У файлі підбору немає параметрів повної точності – перезапустіть `fms dist`.")

    edges = np.array([float(h["left"]) for h in hist] + [float(hist[-1]["right"])])
    freq = np.array([float(h["freq"]) for h in hist])
    width = edges[1] - edges[0]
    n = len(data)

    fig, ax = plt.subplots(figsize=(9, 5.2), dpi=dpi)
    fig.patch.set_facecolor(SURFACE)
    ax.set_facecolor(SURFACE)
    ax.bar(edges[:-1], freq, width=width, align="edge", color=BAR, edgecolor=SURFACE, linewidth=1.5,
           label=f"відносна частота (n = {n})", zorder=2)

    xs = np.linspace(max(0.0, edges[0] - width), edges[-1] + width, 600)
    for i, fit in enumerate(fits[:top]):
        dist = SCIPY_DIST[fit["law"]]
        # щільність, приведена до ймовірності потрапляння в інтервал ширини width
        ys = dist.pdf(xs, *fit["params_raw"]) * width
        verdict = "прийнято" if fit["accepted"] else "відхилено"
        label = (f"{LAW_UA.get(fit['law'], fit['law'])}: χ² = {fit['chi2']:.1f}, "
                 f"χ²кр = {fit['chi2_crit_0.05']:.1f} ({verdict})")
        ax.plot(xs, ys, color=CURVES[i % len(CURVES)], linestyle=LINESTYLES[i % len(LINESTYLES)],
                linewidth=2, label=label, zorder=3)

    mean, std = data.mean(), data.std(ddof=1)
    ax.set_title("Розподіл часу проходження деталей", loc="left", fontsize=13, color=INK, pad=22)
    ax.text(0, 1.02, f"{_title(tag)};  середнє {mean:.0f} с, σ = {std:.0f} с",
            transform=ax.transAxes, fontsize=9.5, color=INK_2)
    ax.set_xlabel("Час проходження, с", color=INK_2)
    ax.set_ylabel("Відносна частота", color=INK_2)
    ax.grid(axis="y", color=GRID, linewidth=0.8, zorder=0)
    ax.set_axisbelow(True)
    for side in ("top", "right"):
        ax.spines[side].set_visible(False)
    for side in ("left", "bottom"):
        ax.spines[side].set_color(GRID)
    ax.tick_params(colors=INK_2, labelsize=9)
    ax.set_xlim(xs[0], xs[-1])
    ax.set_ylim(0, max(freq.max(), *(l.get_ydata().max() for l in ax.lines)) * 1.12)
    leg = ax.legend(frameon=False, fontsize=9, loc="upper right")
    for text in leg.get_texts():
        text.set_color(INK)
    fig.tight_layout()

    out = out or results / f"dist_hist_{tag}.png"
    fig.savefig(out, facecolor=SURFACE)
    plt.close(fig)
    return out

Що на графіку: відносні частоти з тими самими інтервалами, що й у χ², і поверх них криві трьох найкращих законів. У легенді для кожного закону стоять χ², χ²кр і висновок «прийнято / відхилено».
Кольори і лінії: криві розрізняються і кольором, і типом лінії (суцільна, штрихова, пунктирна), тож графік читається й у чорно-білому друці.
Параметри:
--tag вибирає, який результат малювати; без нього будуються графіки для всіх знайдених у results/;
--top задає кількість кривих;
--dpi задає роздільність (за замовчуванням 200, для Word достатньо).
Зміни в dist: тепер команда додатково зберігає dist_fits_*.json з точними параметрами законів, з яких будуються криві. Тому для старих результатів dist треба перезапустити, інакше plot-dist попросить це зробити.
